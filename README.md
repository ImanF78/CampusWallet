# CampusWallet

## Purpose
The application aims to encourage better financial management among university students by providing a simple way to monitor income, expenses and budgets.

## Main Features
- Student registration and login
- Income tracking
- Expense tracking
- Available balance calculation
- Monthly budget management
- Transaction history
- Separate student accounts

## Technologies Used
- Kotlin
- Android Studio
- XML
- Room Database
- SharedPreferences

## Installation
1. Clone the CampusWallet repository.
2. Open the project in Android Studio.
3. Allow Gradle to sync.
4. Run the application on an Android emulator or device.
